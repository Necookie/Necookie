## Thesis

> **Minecraft-Based Disaster Preparedness Simulation with Behavioral Analytics and Explainable Artificial Intelligence**

The work explores disaster-preparedness training inside Minecraft, then uses behavioral analytics and explainable AI to make participant decisions easier to study.
